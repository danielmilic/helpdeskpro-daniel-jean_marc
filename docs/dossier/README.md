# Dossier d'industrialisation HelpDesk Pro

Un fichier par partie, complété au fil des trois jours :

1. `01-note-de-cadrage.md` — pourquoi industrialiser, bénéfices attendus, 3 exemples concrets (jour 1)
2. `02-schema-pipeline.md` — schéma du pipeline (déclencheurs, jobs, runners, registre, gates) et justification de chaque élément (jour 2)
3. `03-plan-de-deploiement.md` — environnements, stratégie retenue et écartées, rollback, contrôles de sécurité (jour 3)
4. `04-configuration-iac.md` — Compose, `.env.example`, Terraform, gestion des secrets : choix expliqués (jour 3)
5. `05-rapport-de-mesure.md` — chronologie d'un changement, métriques DORA, durées avant / après optimisation, goulot, 3 propositions (jour 3)
